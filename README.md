Colors Fun 🎨

Colors Fun is a vibrant, modern color-sorting puzzle game built with Python and KivyMD. Designed to be relaxing yet mentally engaging, the game challenges players to solve hue and gradient puzzles by arranging scrambled colors into harmonious chromatic sequences.

Whether you are looking for a quick brain exercise or a calming offline gaming experience, Colors Fun offers smooth gameplay tailored for both mobile devices and desktop screens.

Key Features

Offline Play — Fully functional without an internet connection.

Intuitive UI — Clean, modern Material Design interface powered by KivyMD.

Cross-Platform — Playable on both Android (.apk).

Lightweight & Fast — Optimized for smooth performance across a wide range of devices.

Downloads & Releases

Android: Download the pre-compiled .apk from the official Releases tab.

itch.io: Play or download the game on https://business-man3.itch.io.

Technical Stack

Language: Python 3

UI Framework: Kivy & KivyMD

Build Tools: Buildozer (Android compilation)
